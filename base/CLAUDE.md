# {{APP_NAME}} — Claude Code Project Rules

Tauri v2 desktop app: React 19 + TypeScript frontend ↔ Rust backend via IPC.
Generated by [TauriKit](https://taurikit.dev).

## Architecture

```
Frontend (React 19 + TypeScript + Vite)   →  src/
  ↕ IPC bridge: invoke("command_name", { args })
Backend (Rust + Tauri v2)                 →  src-tauri/src/
  ↕ Native OS APIs, filesystem, HTTP, persistent storage
```

The frontend runs in a webview. The backend is a native Rust process.
All communication goes through `invoke()` — never use `fetch()` for backend calls.

## Adding a New Tauri Command (5-step pattern)

Every new backend feature follows this exact sequence:

1. **Rust handler** — Create `src-tauri/src/commands/myfeature.rs`:
   ```rust
   use crate::error::AppResult;
   use crate::state::SharedState;
   use tauri::State;

   #[tauri::command]
   pub async fn do_something(state: State<'_, SharedState>, input: String) -> AppResult<String> {
       let _state = state.lock().unwrap();
       Ok(format!("Result: {input}"))
   }
   ```

2. **Register module** — In `src-tauri/src/commands/mod.rs`: `pub mod myfeature;`

3. **Add to handler** — In `src-tauri/src/lib.rs`, add to `generate_handler![]`:
   `commands::myfeature::do_something,`

4. **TypeScript wrapper** — In `src/lib/tauri.ts`:
   ```typescript
   export async function doSomething(input: string): Promise<string> {
     return invoke("do_something", { input });
   }
   ```

5. **Use in React** — `import * as api from "@/lib/tauri"; await api.doSomething("hi");`

## Naming Conventions

- Rust commands: `snake_case` (`do_something`)
- TypeScript wrappers: `camelCase` (`doSomething`)
- Rust models: `#[serde(rename_all = "camelCase")]` on all structs
- TypeScript types mirror Rust models in `src/lib/types.ts`, fields in `camelCase`
- Imports use `@/` path alias (maps to `src/`)

## Extending the App

**New page/view**: Create `src/components/MyView.tsx`, wire in `src/App.tsx`
**Zustand store**: Add fields + setters in `src/store/appStore.ts`
**Error types**: Add variant to `AppError` in `src-tauri/src/error.rs`
**App state**: Add fields to `AppState` in `src-tauri/src/state.rs`
**Settings**: Add field to Rust `AppSettings` + mirror in TS `types.ts`
**Plugin**: Add crate to `Cargo.toml`, register in `lib.rs`, grant in `capabilities/default.json`

## Hard Rules — Do NOT

- Use browser `window.close()`, `window.minimize()`, etc. — use Tauri's `appWindow` API
- Use `fetch()` for backend calls — use `invoke()` wrappers in `src/lib/tauri.ts`
- Add Rust commands without a typed TypeScript wrapper in `src/lib/tauri.ts`
- Skip `#[serde(rename_all = "camelCase")]` on Rust model structs
- Put secrets in frontend code — use `.env` with non-`VITE_` prefixed vars for backend-only secrets
- Modify `TitleBar.tsx` window control logic unless explicitly asked — it handles macOS/Windows/Linux natively
- Use Redux — this project uses Zustand exclusively
- Import from `node_modules` paths — use `@/` alias for all project imports

## Platform-Specific Code

Frontend:
```typescript
import { getDesktopPlatform } from "@/lib/platform";
const os = getDesktopPlatform(); // "macos" | "windows" | "linux"
```

Backend:
```rust
#[cfg(target_os = "macos")]    fn macos_only() { }
#[cfg(target_os = "windows")]  fn windows_only() { }
#[cfg(target_os = "linux")]    fn linux_only() { }
```

## Environment Variables

- `.env` — local secrets, gitignored, never committed
- `.env.example` — template with placeholders (committed)
- `VITE_` prefix — accessible in frontend via `import.meta.env.VITE_*`
- Non-prefixed — backend only via `std::env::var()`

```bash
cd src-tauri && cargo check   # Type-check Rust without building
cd src-tauri && cargo test    # Run Rust tests
bun test               # Run frontend tests
```

## Styling

- Tailwind CSS v4 with theme CSS variables in `src/index.css`
- Use `cn()` from `@/lib/utils` for conditional class merging
- UI primitives in `src/components/ui/` — use these before creating new ones
- Custom title bar: window has `decorations: false`, TitleBar.tsx handles all chrome

## Code Quality

- Rust errors: Use `thiserror` derive macro, all errors implement `Serialize` for IPC
- TypeScript: Strict mode enabled, no `any` types
- All Tauri commands return `AppResult<T>` (never raw `Result`)
- Settings persisted via `tauri-plugin-store` to JSON on disk
- State shared via `Mutex<AppState>` — keep critical sections short
