## Setup

### 1. Install dependencies

```bash
bun install
```

### 2. Configure environment

```bash
cp .env.example .env
```

Edit `.env` and fill in your values. See comments in `.env.example` for instructions.

### 3. Create a GitHub OAuth App (auth-github module)

1. Go to [GitHub Settings → Developer Settings → OAuth Apps](https://github.com/settings/developers)
2. Click **New OAuth App**
3. Set:
   - **Application name**: `{{APP_NAME}}`
   - **Homepage URL**: `http://localhost`
   - **Callback URL**: *(leave blank — Device Flow doesn't use a callback)*
4. Copy the **Client ID** and paste it into `.env`:
   ```
   GITHUB_CLIENT_ID=your_client_id_here
   ```

### 4. Run in development

```bash
bun tauri dev
```

## Adding a New Tauri Command

**1. Create the Rust handler** in `src-tauri/src/commands/myfeature.rs`:

```rust
use crate::error::AppResult;
use crate::state::SharedState;
use tauri::State;

#[tauri::command]
pub async fn my_command(
    state: State<'_, SharedState>,
    input: String,
) -> AppResult<String> {
    // Your logic here
    Ok(format!("Hello, {input}!"))
}
```

**2. Register it** in `src-tauri/src/commands/mod.rs`:

```rust
pub mod auth;
pub mod myfeature;   // add this
pub mod settings;
```

**3. Add to the handler list** in `src-tauri/src/lib.rs`:

```rust
.invoke_handler(tauri::generate_handler![
    commands::auth::login,
    // ...
    commands::myfeature::my_command,  // add this
])
```

**4. Add a typed wrapper** in `src/lib/tauri.ts`:

```typescript
export async function myCommand(input: string): Promise<string> {
  return invoke("my_command", { input });
}
```

**5. Use it** in any React component:

```typescript
import * as api from "@/lib/tauri";

const result = await api.myCommand("world");
```

## Troubleshooting

**`error: linker 'link.exe' not found` (Windows)**
→ Install [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)

**`webkit2gtk not found` (Linux)**
→ `sudo apt install libwebkit2gtk-4.1-dev`

**App opens but shows a blank screen**
→ Right-click → Inspect → check the Console tab for JavaScript errors

**"GITHUB_CLIENT_ID is not set"**
→ Copy `.env.example` to `.env` and fill in `GITHUB_CLIENT_ID`

**OAuth Device Flow never completes**
→ Make sure your GitHub OAuth App's Client ID matches `GITHUB_CLIENT_ID` in `.env`
→ Verify you're entering the user code at https://github.com/login/device
